# Capstone Compass: AI‑Driven Project Finder for Final‑Year Students  

## 📌 Overview  
Choosing a final‑year project is often stressful. Students get overwhelmed by too many generic ideas from tools like ChatGPT or Gemini, which don’t match their skills, interests, or faculty expectations. This leads to confusion, wasted time, and difficulty in getting approvals.  

**Capstone Compass** is an AI agent built to solve this problem. It takes in student profiles (skills, interests, constraints) and faculty preferences, then recommends a handful of unique, feasible, and mentor‑friendly project ideas. Each idea comes with a problem statement, expected impact, required tools, and feasibility analysis — making it ready for faculty discussion.  

---

## 🎯 Features  
- Personalized project suggestions based on student profiles  
- Faculty bias handling to improve approval chances  
- Guardrails to avoid repetitive or impractical topics  
- Ready‑to‑use outputs with problem, impact, tools, and feasibility  
- Comparison dashboard vs. generic AI tools  
- Team collaboration support by balancing skills across members  

---

## ⚙️ Tech Stack  
- **Frontend:** React / Next.js  
- **Backend:** Node.js / Express + Database  
- **AI/ML:** Recommendation system + LLM integration  
- **Cloud:** AWS / Azure / Render  
- **Version Control:** GitHub  

---

## 🚀 How It Works  
1. Student enters their profile (skills, interests, constraints).  
2. System checks faculty preferences and past project data.  
3. AI generates project ideas.  
4. Guardrails filter out weak or repetitive suggestions.  
5. Final output: 3–5 strong, feasible, mentor‑friendly projects.  

---

## 📈 Why It Matters  
Capstone Compass reduces confusion, saves time, and increases the chances of faculty approval. It’s practical, easy to demo, and directly useful for both students and mentors.
